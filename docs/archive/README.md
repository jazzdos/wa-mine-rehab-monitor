# Archive

Superseded working documents: session handoffs, executed or superseded
implementation plans, and pre-execution reviews whose content is fully
absorbed into the authoritative records (`docs/decisions/`,
`docs/checkpoints/`, `docs/amendments-and-limitations.md`).

Archived 2026-08-25. Files keep their names; every move is 1:1 from the
original directory (`docs/handoffs/X` → `docs/archive/handoffs/X`,
`docs/plans/X` → `docs/archive/plans/X`, `docs/reviews/X` →
`docs/archive/reviews/X`). Decision and checkpoint records are never
edited retroactively, so citations in them to original paths resolve
here by that rule.

Nothing in this directory governs current work. The live documents are
listed in `docs/ROADMAP.md`.
