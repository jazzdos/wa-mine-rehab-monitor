# DPIRD-020 source re-pin (2026-08-21)

**Trigger.** First live `fetch-region-boundaries` (luminosity, Batch D live
run) refused: `https://data-downloads.slip.wa.gov.au/DPIRD-020/Geopackage`
302 → `/Account/Login` → SLIP SSO (PingFederate) → 403. The CLI stored
the HTML body as `regions.gpkg`; GDAL refused it; the file was unlinked.
The 2026-08-15 implementation plan had already recorded the same host as
auth-gated for DMIRS; the 2026-08-16 DPIRD-020 pin was never fetched live.

**Decision.** Re-pin to the SLIP public ArcGIS REST layer listed on the
same Data WA record (`.../SLIP_Public_Services/Boundaries/MapServer/25`),
`f=geojson`, `outSR=4326`, `orderByFields=objectid`. Licence re-verified
2026-08-21 via `package_show`: CC-BY-4.0, unchanged. The raw snapshot
stores the GeoJSON bytes as fetched (`regions.geojson`); a shape guard
refuses non-FeatureCollection bodies and `exceededTransferLimit`.

**Verified against `load_regions` (2026-08-21).** 9 features; names
Gascoyne, Goldfields-Esperance, Great Southern, Kimberley, Mid West, Peel,
Pilbara, South West, Wheatbelt; 0 invalid/empty geometries; total area
2,522,466 km² in EPSG:3577. Pairwise interior intersections are 1–429 m²
digitising slivers (MultiPolygon/GeometryCollection typed); the loader's
overlap check refuses only `Polygon` intersections, so they pass, and the
frozen protocol's `boundary_tie` procedure resolves ambiguous points.
Tightening that check is out of scope and would need a protocol decision.

**Not changed.** Loader contract, snapshot layout, manifests, the frozen
D3 protocol (region source names unchanged).
