# DPIRD-020 Region Boundaries Re-pin Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use kit:build-flow to execute this plan.

**Goal:** Make `fetch-region-boundaries` work again by re-pinning the DPIRD-020 source from the login-gated SLIP download portal to the anonymous SLIP public ArcGIS REST layer, storing the as-fetched GeoJSON.

**Architecture:** The pinned URL `https://data-downloads.slip.wa.gov.au/DPIRD-020/Geopackage` now 302s to SLIP SSO and ends in 403, so the CLI wrote an HTML body as `regions.gpkg` and GDAL refused it (live run 2026-08-21 on luminosity). The Data WA catalogue record `regional-development-commission-boundaries` (CC-BY-4.0, verified 2026-08-21 via the CKAN API) lists the same dataset on `https://public-services.slip.wa.gov.au/public/rest/services/SLIP_Public_Services/Boundaries/MapServer/25`, which answers anonymously: 9 features, name field `region`, CRS GDA2020 (wkid 7844), `maxRecordCount` 10000. The fix keeps the fetch seam, snapshot layout, and loader contract; it changes the URL, the artefact name (`regions.geojson` — the bytes are stored exactly as fetched), adds a GeoJSON-shape guard so a login page can never be mistaken for data, and teaches `load_regions` the `region` column name. Nothing downstream of `load_regions` changes.

**Tech Stack:** Python 3.12, typer, geopandas, pytest. Run `kit:code-standards` (Python) before editing.

**Verified facts the tests encode:** the REST GeoJSON loads through `load_regions` with all nine names (`Gascoyne, Goldfields-Esperance, Great Southern, Kimberley, Mid West, Peel, Pilbara, South West, Wheatbelt`), valid Polygon/MultiPolygon geometries, no `exceededTransferLimit` key. Pairwise interior intersections are 1–429 m² digitising slivers typed MultiPolygon/GeometryCollection; the existing overlap check refuses only `Polygon` intersections, so they pass, and the frozen protocol's `boundary_tie` procedure resolves ambiguous points. Do not tighten that check in this batch.

Replace `cli.py:301-316`:

```python
#: DPIRD-020 via the SLIP public ArcGIS REST layer, pinned 2026-08-21
#: (Data WA catalogue record `regional-development-commission-boundaries`,
#: licence CC-BY-4.0 re-verified the same day via the CKAN API). The
#: previous pin, `https://data-downloads.slip.wa.gov.au/DPIRD-020/Geopackage`
#: (2026-08-16), now redirects to SLIP SSO and returns 403 anonymously.
#: `orderByFields=objectid` keeps the byte stream -- and so the snapshot
#: digest -- stable across fetches of unchanged data.
_RDC_REGIONS_DOWNLOAD_URL = (
    "https://public-services.slip.wa.gov.au/public/rest/services/"
    "SLIP_Public_Services/Boundaries/MapServer/25/query"
    "?where=1%3D1&outFields=*&outSR=4326&orderByFields=objectid&f=geojson"
)
_RDC_REGIONS_FILENAME = "regions.geojson"


def _fetch_region_boundaries_bytes() -> bytes:
    """Download the pinned DPIRD-020 GeoJSON (network seam, monkeypatchable)."""
    client = HttpClient()
    return client.get_bytes(_RDC_REGIONS_DOWNLOAD_URL)


def _refuse_unless_complete_geojson(payload: bytes) -> None:
    """Refuse by SHAPE before GDAL sees the bytes: a login page or an
    ArcGIS page-limited result must never become a snapshot."""
    try:
        body = json.loads(payload)
    except (UnicodeDecodeError, json.JSONDecodeError) as exc:
        raise RegionPayloadError(
            f"region boundaries payload is not a GeoJSON FeatureCollection: {exc}"
        ) from exc
    if not isinstance(body, dict) or body.get("type") != "FeatureCollection":
        raise RegionPayloadError(
            "region boundaries payload is not a GeoJSON FeatureCollection "
            f"(top-level type={body.get('type')!r} if isinstance(body, dict) else type(body).__name__)"
        )
    if body.get("exceededTransferLimit"):
        raise RegionPayloadError(
            "region boundaries payload has exceededTransferLimit=true -- the REST "
            "layer paged the result; refusing a partial region set"
        )


class RegionPayloadError(ValueError):
    """The fetched region-boundary bytes are not a complete GeoJSON body."""
```
